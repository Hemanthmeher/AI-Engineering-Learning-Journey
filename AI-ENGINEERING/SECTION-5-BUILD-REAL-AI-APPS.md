## 1. LLM vs. Chat Models

### What I Understood:
Earlier, traditional LLMs took raw string prompts and just completed the text (like autocomplete). But modern **Chat Models** structure the conversation using three distinct roles:
- **SystemMessage**: Sets the behavior, tone, or rules for the AI model.
- **HumanMessage**: The prompt or question sent by the user.
- **AIMessage**: The response generated by the model.

This structured format makes it much easier to build conversational assistants and steer the model's behavior accurately.

### Code Implementation:
```python
import os
from langchain_core.messages import SystemMessage, HumanMessage
from langchain_groq import ChatGroq

# Setup Groq model
llm = ChatGroq(
    model="llama-3.3-70b-versatile",
    temperature=0.3,
    api_key=os.environ.get("GROQ_API_KEY")
)

# Sending structured messages to the chat model
messages = [
    SystemMessage(content="You are a helpful coding assistant."),
    HumanMessage(content="Explain what LCEL is in simple terms.")
]

response = llm.invoke(messages)
print(response.content)


2. Prompt Engineering & Chaining (LCEL)
What I Understood:
Instead of formatting strings manually every time, ChatPromptTemplate allows us to create dynamic prompts with variable placeholders.

Using LangChain Expression Language (LCEL), we can connect components using the pipe operator (|).
The data flows naturally: Prompt | Model | OutputParser.

Code Implementation:
Python
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_groq import ChatGroq

llm = ChatGroq(
    model="llama-3.3-70b-versatile",
    temperature=0.2,
    api_key=os.environ.get("GROQ_API_KEY")
)

# Dynamic prompt template
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are an expert tutor in {subject}."),
    ("human", "Explain {topic} in 2 short bullet points.")
])

# Building the chain using LCEL pipe operator
chain = prompt | llm | StrOutputParser()

# Calling the chain
result = chain.invoke({"subject": "AI Engineering", "topic": "Prompt Chaining"})
print(result)



3. Output Parsers
What I Understood:
By default, LLMs return full response objects containing metadata and raw text. StrOutputParser extracts just the clean string response so we can easily pass it to other functions or display it directly to users without unnecessary clutter.

Code Implementation:
Python
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_groq import ChatGroq

llm = ChatGroq(model="llama-3.3-70b-versatile", api_key=os.environ.get("GROQ_API_KEY"))

prompt = ChatPromptTemplate.from_template("Give me 3 keywords for {concept}")
parser = StrOutputParser()

# Chain that returns pure clean string output
chain = prompt | llm | parser

output = chain.invoke({"concept": "LangChain"})
print(f"Clean output: {output}")




4. JSON & Pydantic Integration
What I Understood:
When building real applications, raw string responses are risky because software needs structured data like Python dictionaries or JSON.

By combining Pydantic schemas with PydanticOutputParser, we enforce exact structure, data types, and runtime validation on the AI response before consuming it in our backend or database.

Code Implementation:
Python
import os
from typing import List
from pydantic import BaseModel, Field
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import PydanticOutputParser
from langchain_groq import ChatGroq

# Define the expected structure
class TechStackInfo(BaseModel):
    tool_name: str = Field(description="Name of the software tool")
    category: str = Field(description="Category like Framework, Database, etc.")
    use_cases: List[str] = Field(description="List of top 2 use cases")

parser = PydanticOutputParser(pydantic_object=TechStackInfo)

llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.0, api_key=os.environ.get("GROQ_API_KEY"))

prompt = ChatPromptTemplate.from_messages([
    ("system", "Extract tool details. Output must follow instructions:\n{format_instructions}"),
    ("human", "Tell me about {tool}")
])

chain = prompt | llm | parser

result = chain.invoke({
    "tool": "FastAPI",
    "format_instructions": parser.get_format_instructions()
})

print(f"Tool Name: {result.tool_name}")
print(f"Category: {result.category}")
print(f"Use Cases: {result.use_cases}")
